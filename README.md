# 🚀 OpenCode TeleBridge

> **An advanced, secure, and lightning-fast Telegram & Bale Gateway for the [OpenCode](https://opencode.ai) Coding Assistant.**  
> گیت‌وی قدرتمند، امن و هوشمند تلگرام و بله برای دستیار برنامه‌نویسی و مهندسی OpenCode با قابلیت استریم زنده ابزارها، مدیریت سشن‌ها، و کنترل کامل سیستم لینوکس.

## 📖 درباره پروژه (About)

این پروژه یک ارتباط‌دهنده پیشرفته (Bridge Gateway) میان پیام‌رسان‌های تلگرام و بله با سرور دستیار برنامه‌نویسی **OpenCode** است. با استفاده از این ربات، شما می‌توانید از هر کجای دنیا از طریق تلفن همراه یا دسکتاپ، سرور و کدهای خود را با مدل‌های هوش مصنوعی (مانند Claude 3.7 Sonnet، GPT-4o، DeepSeek R1 و غیره) هدایت، بازبینی، عیب‌یابی و اجرا کنید.

تمام کلیدهای امنیتی و دسترسی‌ها به صورت کاملاً محلی در فایل `.env` نگهداری می‌شوند و هیچ‌گونه اطلاعاتی در مخزن گیت ذخیره نمی‌شود.

## 🌟 قابلیت‌های کلیدی

### ۱. تعامل هوشمند و استریم زنده اجرای ابزارها (Hermes Agent Live Execution Feed)
- **ردیابی زنده اجرای ابزارها:** هنگام اجرای تسک، مراحل دقیقا مانند دستیار Hermes گزارش می‌شوند:
  - `💻 terminal`: نمایش کامندهای شل در حال اجرا
  - `📖 Reading <file>`: خواندن فایل‌های منبع با شماره خطوط
  - `✍️ Writing <file> (×N)`: ایجاد و نوشتن فایل با جمع‌آوری دفعات متوالی
  - `✏️ Editing <file>`: ویرایش خطوط فایل‌ها
  - `🔍 Searching <query>`: جستجوی کدها و فایل‌ها
  - `🌐 Web search`: جستجو در وب
  - `⚙️ process: "wait ..."`: فرآیندهای پس‌زمینه
- **بنر وضعیت و گام‌های پردازش:**
  - `⏳ Working — 2 min — iteration 14/150, executing bash...`
  - تشخیص خطاهای محدودیت سرویس‌دهنده و نمایش خودکار هشدار:
    `⏱️ The model provider is rate-limiting requests. Please wait a moment and try again.`
- **قفل همزمانی تسک (Concurrency Lock):** تا زمانی که تسک قبلی در حال اجراست و پاسخ کامل نشده، ارسال دستور یا پیام جدید برای حفظ سلامت سشن متوقف شده و با پیام شفاف و دکمه توقف فوری همراه می‌شود:
  `⚠️ ایجنت در حال اجراست — لطفاً منتظر بمانید یا ابتدا /stop را ارسال کنید.`
- **توقف فوری عملیات (`/stop` یا دکمه سینی):** امکان لغو فوری پردازش با یک لمس یا ارسال دستور `/stop`.
- **ری‌اکشن‌های زنده (Reactions):** ربات هنگام دریافت پیام اموجی 👀، در صورت موفقیت 👍 و در صورت خطا 👎 می‌زند.
- **تایپینگ پیوسته:** اکشن `typing` یا `upload_document` هنگام پردازش فعال است.

### ۲. امنیت و تایید دسترسی‌ها با دکمه‌های شیشه‌ای (Interactive Permissions & Questions)
- **درخواست‌های مجوز (Permissions):** هرگاه OpenCode نیاز به اجرای دستور در ترمینال یا دسترسی به فایل خارج از محدوده داشته باشد، دکمه‌های شیشه‌ای زیر ارسال می‌شوند:
  - `✅ تایید یک‌باره (Once)`
  - `🔄 همیشه مجاز (Always)`
  - `❌ رد درخواست (Reject)`
- **سوالات تعاملی (Interactive Questions):** هنگام مواجهه با سوالات چندگزینه‌ای، گزینه‌ها به صورت دکمه‌های شیشه‌ای ارسال شده و با یک کلیک پاسخ به OpenCode بازمی‌گردد.

### ۳. انتخاب مدل و ایجنت هوش مصنوعی (`/model` و `/agent`)
- **سوییچ زنده مدل‌ها:** مشاهده مدل‌های نصب‌شده در سیستم و سوییچ فوری با دکمه شیشه‌ای.
- **تغییر حالت ایجنت:** انتخاب بین حالت‌های اصلی OpenCode:
  - `🔨 Build` (کدنویسی، اجرای ابزارها و ترمینال)
  - `📋 Plan` (طراحی معماری و برنامه‌ریزی بدون ویرایش)
  - `🔍 Explore` (کاوش و جستجوی سریع در کدها)
  - `🚀 General` (انجام وظایف چندمرحله‌ای)

### ۴. کیبورد دسترسی سریع و پایدار (Persistent Reply Keyboard)
- کلیدهای دسترسی سریع ایرانی در سینی پایین تلگرام برای دسترسی یک‌لمسی:
  - `➕ سشن جدید` | `🤖 مدل‌ها` | `🧠 ایجنت`
  - `📝 تغییرات گیت` | `📋 تسک‌ها` | `🌐 اشتراک سشن`
  - `📊 آمار مصرف` | `⚡ ترمینال` | `❓ راهنما`

### ۵. مدیریت پیشرفته سشن‌ها (`/sessions`, `/fork`, `/share`)
- **انشعاب سشن (`/fork`):** ساخت یک شاخه جدید از مکالمه بدون از دست رفتن تاریخچه گذشته.
- **اشتراک‌گذاری وب (`/share`):** ایجاد لینک عمومی در بستر وب برای مشاهده کامل چت در مرورگر با امکان لغو اشتراک.
- **جابجایی بین سشن‌ها (`/sessions`):** فهرست سشن‌های قبلی با دکمه‌های سوییچ سریع.

### ۶. ابزارهای پیشرفته گیت و بازگردانی (`/git`, `/diff`, `/revert`)
- `/git`: بررسی خلاصه فایل‌های تغییر یافته، افزوده شده یا حذف شده به همراه تعداد خطوط.
- `/diff`: مشاهده تغییرات کامل کد (در صورت طولانی بودن، به صورت فایل `.patch` ارسال می‌شود).
- `/revert` و `/unrevert`: بازگردانی سریع آخرین تغییر اعمال‌شده توسط هوش مصنوعی و اعمال مجدد آن.
- `/symbol <name>`: جستجوی توابع و کلاس‌ها در کل پروژه بر پایه LSP.
- `/skills`: مشاهده تمام مهارت‌های نصب‌شده OpenCode.

## 📋 لیست کامل دستورات در تلگرام

| دستور | عملکرد |
|---|---|
| `/cd <مسیر>` | تغییر پوشه کاری ایجنت به دایرکتوری دیگر (یا انتخاب از میانبرها) |
| `/pwd` | نمایش مسیر کاری فعلی ایجنت و لیست سریع فایل‌ها |
| `/post <@channel> <متن>` | ارسال و انتشار مستقیم پیام در کانال‌های تلگرام |
| `/set_channel <@channel>` | تعیین کانال پیش‌فرض جهت ارسال پیام |
| `/channels` | مشاهده وضعیت کانال‌های تلگرام متصل |
| `/whoami` | کارت هویت و مشخصات کاربر (از روی حافظه پایدار) |
| `/memory` | پنل تعاملی مدیریت فایل‌های حافظه (USER, MEMORY, SOUL) |
| `/remember <نکته>` | ثبت نکته دائمی در حافظه دستیار |
| `/soul` | مرام‌نامه، سبک پاسخگویی و خطوط قرمز دستیار |
| `/new` | سشن تازه و پاکسازی تاریخچه مکالمه در مسیر کاری فعلی |
| `/model` | انتخاب مدل هوش مصنوعی با دکمه‌های اینلاین |
| `/agent` | سوییچ حالت ایجنت (Build, Plan, Explore, General) |
| `/git` | مشاهده وضعیت فایل‌های تغییر یافته پروژه |
| `/diff` | مشاهده کامل تغییرات خطوط کد (Git Diff) |
| `/revert` | بازگردانی آخرین تغییر اعمال شده روی کد |
| `/unrevert` | اعمال مجدد تغییرات بازگردانده شده |
| `/share` | دریافت لینک اشتراک‌گذاری وب سشن |
| `/fork` | انشعاب و ایجاد کپی تازه از سشن جاری |
| `/sessions` | مشاهده و جابجایی بین گفتگوهای گذشته |
| `/todo` | مشاهده فهرست اقدامات و وظایف دستیار |
| `/usage` | گزارش دقیق مصرف توکن‌ها و هزینه‌ها |
| `/sh <دستور>` | اجرای دستور مستقیم در ترمینال لینوکس در مسیر کاری جاری |
| `/find <نام>` | جستجوی فایل در محیط پوشه کاری |
| `/symbol <نام>` | جستجوی تابع یا کلاس در کد (LSP) |
| `/cat <مسیر>` | نمایش متن فایل در چت تلگرام |
| `/download <نام یا مسیر>` | ارسال و دانلود مستقیم فایل از سیستم به تلگرام |
| `/skills` | مشاهده مهارت‌های فعال در OpenCode |
| `/status` | بررسی وضعیت سلامت سرور و سشن فعال |
| `/stop` | توقف و لغو فوری پردازش جاری |
| `/help` | راهنمای کامل دستورات |

## 🗣️ قابلیت‌های هوشمند به زبان طبیعی (Natural Language Actions)

شما می‌توانید تمام کارهای بالا را بدون نیاز به حفظ دستورات، مستقیماً به زبان مادری به هوش مصنوعی بگویید:

1. **تغییر مسیر کاری ایجنت:**
   - «برو به پوشه دسکتاپ»
   - «میخوام برم توی پوشه دانلودها و فایل‌ها رو ببینم»
   - «مسیر رو عوض کن به ~/Documents»
   - دستیار مسیر را فوراً تغییر داده و سشن را در آن دایرکتوری مستقر می‌کند.

2. **دانلود و ارسال خودکار فایل به تلگرام:**
   - «فایل کانفیگ رو میخوام برام بفرستی»
   - «فایل 1234.txt رو برام بفرست»
   - «دانلود فایل config.py»
   - دستیار فایل واقعی را مستقیماً به عنوان Document یا Photo در چت تلگرام شما آپلود می‌کند.

3. **ارسال پیام و پست به کانال‌های تلگرام:**
   - «ارسال به کانال @mychannel: سلام دوستان این یک پیام تسته»
   - «یک متن معرفی درباره ربات بنویس و منتشر کن توی کانال @mychannel»
   - دستیار پست را آماده کرده و در صورتی که ربات در آن کانال ادمین باشد، منتشر می‌کند.

## 🚀 راهنمای نصب و راه‌اندازی (Quick Start & Installation)

### ۱. پیش‌نیازها (Prerequisites)
- **پایتون:** Python 3.10 یا بالاتر
- **دستیار OpenCode:** نصب بودن ابزار خط فرمان `opencode`
- **توکن ربات تلگرام:** دریافت از طریق [@BotFather](https://t.me/BotFather)
- **آیدی عددی تلگرام:** دریافت شناسه عددی اکانت خود از طریق [@userinfobot](https://t.me/userinfobot) (جهت احراز هویت امنیتی ربات)

### ۲. کلون کردن مخزن (Clone Repository)
```bash
git clone https://github.com/<your-username>/opencode-telebridge.git
cd opencode-telebridge
```

### ۳. نصب وابستگی‌ها (Install Dependencies)
```bash
pip install -r requirements.txt
```

### ۴. پیکربندی فایل `.env` (Environment Configuration)
فایل نمونه را کپی کرده و اطلاعات خود را در آن وارد کنید:
```bash
cp .env.example .env
nano .env
```

مقادیر کلیدی:
```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
TELEGRAM_ALLOWED_USERS=123456789
OPENCODE_SERVER_URL=http://127.0.0.1:4096
OPENCODE_AUTO_START=true
```

> ⚠️ **توجه امنیتی:** فایل `.env` در فایل `.gitignore` قرار دارد و به هیچ عنوان نباید در مخزن عمومی گیت پوش (Push) شود.

### ۵. اجرا (Run)
می‌توانید به سادگی با اسکریپت `run.sh` یا دستور پایتون پروژه را اجرا نمایید:
```bash
# روش اول: استفاده از اسکریپت خودکار
bash run.sh

# روش دوم: اجرای مستقیم با پایتون
python3 bot.py
```

## 🛰️ راه‌اندازی برای پیام‌رسان بله (Bale Support)
این پروژه دارای پشتیبانی کامل از پیام‌رسان ایرانی **بله** نیز می‌باشد:
1. توکن ربات بله خود را از `BotFather` بله دریافت کرده و در فایل `.env` در متغیر `BALE_BOT_TOKEN` قرار دهید.
2. شناسه کاربری بله خود را در `BALE_ALLOWED_USERS` وارد کنید.
3. ربات بله را اجرا کنید:
```bash
python3 bale_bot.py
```

## 🛠️ مدیریت سرویس در لینوکس (Systemd Service)

برای اجرای همیشگی ربات در پس‌زمینه سرور یا سیستم لینوکسی خود، فایل سرویس را در مسیر سرویس‌های کاربری قرار دهید:

```bash
# ایجاد دایرکتوری سرویس‌های کاربری در صورت عدم وجود
mkdir -p ~/.config/systemd/user/

# کپی کردن فایل سرویس
cp opencode-telegram.service.example ~/.config/systemd/user/opencode-telegram.service

# ویرایش مسیرها در صورت نیاز
nano ~/.config/systemd/user/opencode-telegram.service

# فعال‌سازی و راه‌اندازی سرویس
systemctl --user daemon-reload
systemctl --user enable --now opencode-telegram.service

# بررسی وضعیت
systemctl --user status opencode-telegram.service

# مشاهده لاگ‌های زنده
journalctl --user -u opencode-telegram.service -f
```
